> **화면 표시가 다를 수 있어요.** 도구 설치 명령과 화면은 바뀔 수 있어요. 이 글의 소개는 2026-10-21에 공개 문서를 읽고 정리한 것이고, Blender·Manim은 직접 설치해 돌려 본 것이 아니에요.

## 한 줄 설명

영상 편집 프로그램을 열지 않고, **"이런 장면 만들어 줘"라고 말하면 클로드가 코드를 쓰고, 그 코드가 영상 파일(MP4)이 되는** 방식이에요. 코드는 한 번 만들면 글자·색만 바꿔 여러 개를 찍어 낼 수 있어요.

## 5개 한눈에 비교

| 도구 | 무엇으로 만드나 | 이럴 때 | 난이도 |
|---|---|---|---|
| **HyperFrames** | 웹페이지(HTML)를 영상으로 | 세로 쇼츠, 제목 카드, 자막 | 쉬움 |
| **Remotion** | React 코드를 영상으로 | 차트, 막대가 올라가는 영상 | 보통 |
| **Blender 연결** | 3D 프로그램을 클로드가 조종 | 돌아가는 3D 제품 | 어려움 |
| **Manim** | 수학 설명 영상 전용 | 원리를 그려 가며 설명 | 어려움 |
| **algorithmic-art** | 움직이는 입자 배경 | 영상 뒤에 깔 배경 | 쉬움 |

**처음이면 HyperFrames 하나만 해도 충분해요.** 세로 쇼츠·카드뉴스형 영상은 이것으로 거의 다 돼요. 나머지는 필요가 생길 때 하나씩 더해요.

## 공통 사용 순서

1. 클로드(Code 탭)에서 폴더를 하나 골라요.
2. 도구 설치를 "설치해 줘"로 시키고, 권한 요청을 **읽고** 허용해요.
3. 만들고 싶은 장면을 말해요. 길이·비율·색을 같이 적어요.
   예: "15초 세로 영상, 검은 배경에 주황색 포인트, 제목이 3번 바뀌게"
4. 클로드가 먼저 **계획**(장면 3~5개)을 보여 줘요. 마음에 들면 승인해요.
5. 미리보기를 보고, 고칠 점을 말하고, 마지막에 렌더(영상 파일 만들기)해요.

처음에는 **5~10초짜리**로 시작하세요. 길수록 렌더가 오래 걸려요.

## 3번 Blender 연결 — 검토

**무엇인가**: 무료 3D 프로그램 Blender 안에서 클로드가 물체·재질·조명·카메라를 만들게 하는 연결(MCP)이에요. 비공식 커뮤니티 도구(MIT 라이선스, 깃허브 별 약 3만 2천 개)로 널리 쓰여요. 옛 이름 `blender-mcp`가 `mcp-for-blender`로 바뀌었고, 두 이름의 안내가 섞여 있어요.

**설치가 하는 일**: ① Blender 안에 애드온(부가 기능)을 넣고 ② 켜면 Blender 안에서 소켓 서버가 열리고 ③ 클로드가 거기에 명령을 보내요. Blender 자체는 따로 설치해야 해요.

**알아 둘 점 (중요한 순서)**

1. **클로드가 Blender 안에서 마음대로 파이썬 코드를 실행할 수 있어요.** 파일 삭제·외부 프로그램 실행도 이론상 가능해요. 안전 모드(`BLENDER_MCP_SAFE_MODE=1`)가 있지만 **기본은 꺼짐**이에요. 작업 파일은 **저장해 두고** 시작하세요.
2. **소켓 서버에 인증이 없어요.** 내 컴퓨터 안(localhost)에서만 쓰고, 다른 컴퓨터에 열지 마세요.
3. **사용 기록을 기본으로 조금 보내요.** 익명 번호·도구 이름·성공 여부 정도인데, 문서에 "서비스 개선·연구·AI 학습에 쓸 수 있다"고 적혀 있어요. 끄려면 `DISABLE_TELEMETRY=true`. 프롬프트·화면 같은 내용은 동의한 경우에만 수집돼요.
4. **외부 3D 자료 서비스는 키가 필요해요.** Poly Haven은 키 없이 되고, Sketchfab·Hyper3D 등은 API 키(비밀번호 같은 것)가 필요하고 일부는 유료예요. 키는 채팅에 붙이지 마세요.
5. **자료마다 저작권 조건이 달라요.** Poly Haven은 CC0(자유), Poly Pizza는 상당수가 CC BY(**만든 사람 표기 필수**)예요. 영상에 쓰면 출처를 적어요.
6. 한 번에 MCP 서버를 하나만 연결해요.

**내 컴퓨터 상태**: Blender가 설치되어 있지 않아요(uv·ffmpeg는 있음). 쓰려면 Blender부터 받아야 하고, 렌더가 무거워서 맥에서는 짧은 장면부터 해야 해요.

**판정: 지금은 보류.** 쇼츠·카드형 영상에는 필요 없어요. "3D 제품이 돌아가는 장면"이 꼭 필요할 때, 안전 모드를 켜고 빈 Blender 파일에서 시작하세요.

## 4번 Manim — 검토

**무엇인가**: 수학 채널 3Blue1Brown이 쓰는 애니메이션 라이브러리(Manim)를 클로드 스킬로 묶은 것이에요. 순서는 **내레이션 대본 → 음성 → 코드 → 렌더 → 영상 합치기 → 브라우저에서 보기**예요. 뷰어에서 시간대별 메모를 붙여 클로드에게 고쳐 달라고 할 수 있어요. MIT 라이선스, 개인 저장소(별 약 180개, 커밋 43개)라 Blender보다 훨씬 작은 프로젝트예요.

**알아 둘 점**

1. **소개 글이 빠뜨린 준비물이 있어요.** 글에는 `brew install cairo pkg-config ffmpeg`만 나오는데, 저장소 설명에는 수식 글자를 그리는 **MacTeX(LaTeX)** 도 필요하다고 해요. 용량이 큰 설치(수 GB)라 시간과 디스크가 들어요.
2. **음성은 내 컴퓨터에서 도는 Kokoro 모델**이에요. API 키도 결제도 없어요. 다만 이 모델이 **한국어를 지원하는지는 확인하지 못했어요.** 한국어 내레이션이 목적이면 설치 전에 반드시 확인하세요. 영어 내레이션만 확실해요.
3. **클로드가 만든 파이썬 코드를 내 컴퓨터에서 실행**해요(렌더·합치기 명령 포함). 폴더를 따로 만들고 권한 요청을 읽으세요.
4. 설치가 `~/.claude/skills`에 **심링크**를 걸어요. 개인 저장소 코드가 내 스킬 폴더에 들어오는 셈이니, 설치 전에 저장소 내용을 한 번 훑어보세요.
5. 결과물은 `~/.manim-skill/` 아래에 쌓여요.

**내 컴퓨터 상태**: `uv`와 `ffmpeg`는 이미 있고, cairo·MacTeX는 확인하지 않았어요.

**판정: 쓸 곳이 분명할 때만, 영어 설명 영상부터.** "원리를 도형으로 풀어 보여 주는 영상"(예: 소리 주파수와 파동)에는 잘 맞아요. 하지만 한국어 음성과 MacTeX 부담이 있어서, 먼저 5~10초짜리 한 장면만 시험해 보는 것을 권해요.

## 100개 변형 찍어 내기

장면 하나를 완성한 뒤 이렇게 시켜요.

> "이 장면에서 바뀌는 글자·색·아이콘을 변수로 빼 줘. titles.csv 100줄을 읽어서 한꺼번에 렌더하고, 글자가 화면을 넘치는 건 건너뛰고 목록으로 알려 줘."

HyperFrames·Remotion에서 돼요. 렌더 전에 **3개만 먼저** 찍어 보세요.

## 자주 막히는 곳

| 증상 | 대처 |
|---|---|
| Blender가 연결 안 됨 | Blender를 켜 두고, 애드온이 켜졌는지 확인, 설치 후 Blender 재시작 |
| `brew` 없다고 나옴 | 맥용 설치 도구(Homebrew)부터 설치 |
| 렌더가 너무 느림 | 5~10초로 줄여서 먼저 확인 |
| 설치 명령이 낯설다 | 그대로 실행하지 말고 클로드에게 "이 명령이 뭘 하는지 설명해 줘"부터 |

## 지켜야 할 것

- 설치 명령은 **출처(HeyGen·Remotion·Anthropic 공식 / 개인 저장소)** 를 확인하고 실행해요.
- 키·비밀번호는 채팅과 깃허브에 올리지 않아요.
- 영상에 쓴 사진·3D 자료는 **라이선스 조건과 출처 표기**를 지켜요.
