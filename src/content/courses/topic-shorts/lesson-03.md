video-style 스킬은 공개 저장소 [osam555/video-style-skill](https://github.com/osam555/video-style-skill) 에 있어요. Claude Code 대화창에 두 줄만 입력하면 돼요.

```

```

플러그인 명령이 막혀 있으면 저장소의 `plugins/video-style/skills/video-style` 폴더를 `%USERPROFILE%\.claude\skills\` (Windows) 또는 `~/.claude/skills/` (macOS) 아래에 복사해도 돼요.

## 톤을 먼저 정하는 이유

그림체를 정하지 않고 이미지 프롬프트를 쓰면 컷마다 화풍이 흔들려요. 톤을 먼저 정하면 뒤의 모든 결정(움직임·전환·프롬프트 문구)이 한 줄에서 나와요. Ai-Con Lab 의 영상 [「클로드로 만든 모션그래픽 20가지 톤」](https://youtu.be/oCRQP5S-900)이 끝에서 묻는 세 질문을 그대로 절차로 만든 게 video-style 스킬이에요.

## 1. 주제를 이야기 세 칸으로

```
core   「아리랑은 알리라 — 알게 될 것이다」      (한 문장으로 말하는 결론)
belief 「한글에도 뜻이 숨어 있다(알·얼)」          (시청자가 믿게 될 것)
scene  「늘 듣던 노래가 새로 들린다」             (시청자 일상의 구체 장면)
```

## 2. 세 질문

1. **내 이야기에는 어떤 옷이 어울리나** — scene 이 지하철·설거지면 사람 냄새 나는 톤, 쪽수·퍼센트면 선과 숫자가 그려지는 톤.
2. **그 옷에 맞는 이야기 방식은** — 컷으로 끊을지, 한 카메라로 흐를지, 말하는 순간 그려질지.
3. **그 방식대로 어떻게 움직이나** — 톤마다 「움직임 규칙 한 문장」. 그림체보다 이 한 문장이 톤을 만들어요.

## 3. 갈래별 기본값

| 갈래 | 1순위 | 2순위 | 움직임 규칙 |
|---|---|---|---|
| 이론·설명(쪽수·숫자·단계) | 칠판·인포그래픽 | 청사진 | 선 → 숫자 → 결론 하나씩 |
| 감성(후기의 장면) | 애니 | 손 그림 · 수묵 · 옛 필름 | 그림은 멈추고 카메라만 / 시간차로 하나씩 / 먹이 번지고 나머지는 비운다 |
| 훈련·따라 하기 | 미니멀 UI | 카툰 | 덜어낼수록 좋다 / 캐릭터가 숨 쉬는 순간 |
| 앱·책 홍보 | 미니멀 UI | 크롬·유리 | 실기기 화면이 주인공 / 천천히 돌 때 빛만 |
| 어린이 | 클레이 | 복셀 | 꾹 눌렸다 통 튀는 탄성 / 말하는 대로 블록이 쌓임 |
| 우리나라 이야기·역사 | 수묵 | 손 그림 | 먹이 천천히 번지고 나머지는 하얗게 비운다 |

## 4. 22가지 톤 카탈로그

| # | 톤 | 움직임 규칙 | 맞는 주제 |
|---|---|---|---|
| 1 | 손 그림 | 한꺼번에 말고 시간차로 하나씩 | AI 티를 줄일 때, 감성 |
| 2 | 콜라주 | 조각이 박자에 맞춰 툭툭 | 컨셉 확실한 트렌디(글자 주의) |
| 3 | 화이트보드 | 말하는 순간 마커가 그린다 | 정보 전달(글자 주의) |
| 4 | 칠판·인포그래픽 | 선 → 숫자 → 결론 하나씩 | 지도·차트·타임라인 |
| 5 | 미니멀 UI | 덜어낼수록 좋다 | 앱·서비스, 훈련 |
| 6 | 청사진 | 연필선 → 치수선 → 제자리에 내려앉음 | 정보, 자막 대비 좋음 |
| 7 | 단면·기계 | 부품이 하나씩 빛나며 돌아간다 | 「어떻게 작동해요?」 |
| 8 | 크롬·유리 | 천천히 돌 때 빛만 | 패션·브랜드·아이콘 |
| 9 | 시네마틱 3D | 컷 거의 없음, 카메라 한 대가 난다 | 예고편·세계관 |
| 10 | 복셀 | 말하는 대로 블록이 쌓인다 | 어려운 내용을 놀이처럼 |
| 11 | 도트·픽셀 | 칸 단위로 뚝뚝 | 게임·레트로·밈 |
| 12 | 제너러티브(입자) | 컷 없이 한 모양이 다른 모양으로 | 음악·인트로 |
| 13 | 다크 네온 | 꼭 필요한 곳에만 빛 | AI·보안·묵직한 기술 |
| 14 | 사이버펑크 | 가까운 건물 빠르게, 먼 건물 느리게 | SF·게임 |
| 15 | HUD·홀로그램 | 작은 움직임이 여러 군데서 동시에 | 테크 제품(숫자 주의) |
| 16 | 아스키 | 글자가 모여 그림이 된다 | 코딩·AI(글자) |
| 17 | 클레이 | 꾹 눌렸다 통 튀는 탄성 | 친근한 서비스·어린이 |
| 18 | 스톱모션 | 초당 12장, 살짝 끊기는 손맛 | 언박싱·인형극 |
| 19 | 카툰 | 캐릭터가 숨 쉬는 순간 | 마스코트·친근한 교육 |
| 20 | 애니 | 그림은 멈춰 두고 카메라만 천천히 | 감성 장면 |
| 21 | 수묵 | 먹이 천천히 번지고 나머지는 하얗게 비운다 | 우리나라 이야기·역사 |
| 22 | 옛 필름 | 빛바랜 질감 위에 지난 장면 한 장씩 | 회상·옛 역사 |

글자가 그려지는 톤(화이트보드·콜라주·HUD·아스키)은 자막 검사와 부딪혀 글자 대신 도형으로 바꿔 써요. 공통 규칙 넷: 등장은 시간차 · 말하는 순간 그려진다 · 어두운 화면에서는 빛 하나만 · 전환은 컷이 아니라 변형.

## 5. 톤 결정 블록

결과는 한 덩어리로 검토본 머리에 남겨요. **한 시리즈 안에서는 톤을 바꾸지 않고, 톤 문구는 뒤의 모든 프롬프트 맨 앞에 한 글자도 바꾸지 않고 붙여요.**

```
## 톤 결정
- 이야기: core 「…」 / belief 「…」 / scene 「…」
- 갈래: 이론 | 감성 | 훈련 | 홍보 | 어린이
- 톤: 1순위 ○○ — 이유 한 줄 / 2순위 ○○ — 이유 한 줄
- 움직임 규칙: (그 톤의 한 문장 그대로)
- 전환: 컷 ○회 / 변형 — 어떤 동작으로 다음 장면이 되나
- 주의: 글자 없는 배경 · 자막 대비 · 실존 인물 없음 · 각주
```

아리랑 편의 블록은 이랬어요. 갈래 감성·우리나라 이야기 → 1순위 수묵, 2순위 손 그림. 뺀 후보: 클레이는 다른 시리즈와 섞임, 옛 필름은 「앞으로 알게 될 것이다」라는 미래형 결론과 어긋남, 인포그래픽은 글자 톤. 사람은 「수묵 좋다」 한마디로 확정했어요.
