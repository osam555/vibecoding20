## A. AI 영상 생성 — 프롬프트 제출과 다운로드 (repl)

장면마다 6초짜리 영상을 만드는 사이트에, 장면 프롬프트를 넣고 다 만들어지면 받아 오는 일입니다.

**방법**
1. 사람이 영상 생성 사이트 탭을 하나 열어 두고, 그 탭 번호를 설정에 적어 둡니다.
2. 스크립트가 `attachBrowserTab(탭번호)` 로 그 탭에 붙습니다.
3. 프롬프트 입력칸에 글을 넣습니다. 이런 편집기는 일반 입력칸이 아니어서, `document.execCommand('insertText', ...)` 로 넣어야 화면이 알아듣습니다.
4. 한 번 호출에 **프롬프트 4개씩** 넣습니다(15강의 120초 제한).
5. 받을 때는 결과 칸 → 다운로드 → 화질 순서로 누르고, `~/Downloads` 에 생긴 파일을 작업 폴더로 옮깁니다.

**함정**
- 작업 탭이 하나뿐이라 **한 번에 한 편만** 돌립니다. 두 편을 동시에 돌리면 서로의 프롬프트가 섞입니다.
- 생성은 장면당 크레딧이 듭니다. 장면 수 × 단가를 미리 계산해 두세요.

## B. 이미지 → 영상 일괄 생성 (exec)

미리 만든 그림을 첫 프레임으로 넣고 움직이게 하는 일은 화면 구성이 자주 바뀌어 스크립트로 고정하기 어렵습니다. 그래서 에이전트에게 말로 맡깁니다.

```
아래 이미지 5장을 순서대로 "프레임 → 영상"으로 만들어 줘.
- 이미지: ./frames/cut01.png ~ cut05.png
- 각 결과는 cut01.mp4 처럼 같은 이름으로 ./clips/ 에 저장
- 끝나면 쓴 크레딧을 알려 줘
```

```bash
aside exec --permission full-access "$(cat flow_order.txt)"
```

**함정**
- 가끔 **이전 영상을 한 번 더 받아** 중복이 생깁니다. 받은 파일 길이·해시로 겹침을 확인하세요.
- "비정상 활동" 경고가 뜨면 새로고침하고 천천히 다시 시도하게 지시합니다.
- 진행 중 방향을 바꾸려면 `aside session list` 로 세션 번호를 찾아 `aside session steer <번호> "..."` 로 고칩니다.

## C. 유튜브 스튜디오 업로드

**repl 방식(대기열)**: 업로드할 편을 대기열 파일에 한 줄씩 적고, 스크립트가 한 편씩 꺼내 올립니다.
1. 영상 파일을 받아 세션 폴더에 둡니다.
2. 파일 선택칸에 `setInputFiles(...)` 로 넣습니다.
3. 제목·설명을 입력하고, 재생목록·공개 설정을 누른 뒤 게시합니다.

**exec 방식(아침 예약)**: 여러 편을 한 세션에 맡기되, 프롬프트에 "먼저 업로드용 repl 함수를 하나 만들고 그걸 재사용하라"고 적습니다. 답에서 `youtube.com/shorts/...` 링크를 뽑아 기록하고, 확인은 별도 세션이 합니다. 편마다 재확인을 빼서 한 편에 1분씩 아낍니다.

> **용어 풀이** API 할당량 = 유튜브가 하루에 허락하는 공식 업로드·조회 횟수. 업로드는 할당량을 많이 먹어서, 브라우저로 올리면 그만큼 아낄 수 있습니다.

## D. 고정 댓글 (repl)

유튜브 공개 API로는 댓글을 **고정**할 수 없습니다. 그래서 시청 페이지를 열어 댓글을 쓰고 고정 메뉴를 누릅니다.

**함정 — 비공개 영상은 댓글이 안 보인다.** 예약 공개 전 영상에 고정 댓글을 미리 달려면:
1. API로 잠깐 **일부 공개**로 바꾸고
2. 댓글을 달아 고정한 뒤
3. 원래 상태(비공개 + 원래 예약 시각)로 **반드시 되돌립니다**(실패해도 되돌리도록 `finally` 에).

---

::: practice
**실습 미션 — 내 영상 한 편에 고정 댓글 달기(수동 확인 포함)**

- [ ] repl로 내 영상 시청 페이지를 열고 `snapshot` 에서 댓글 입력칸 `ref` 를 찾았다
- [ ] 댓글을 쓰는 단계까지만 자동으로 하고, 고정은 내가 화면에서 직접 눌러 봤다
- [ ] 같은 일을 exec로 맡긴다면 프롬프트를 어떻게 쓸지 3줄로 적었다
:::

## 오늘의 체크리스트

- 같은 순서로 누르는 일은 repl, 화면 판단이 필요하면 exec
- 영상 생성 탭은 하나 — 한 번에 한 편
- 공개 상태를 바꿨다면 반드시 되돌리기
