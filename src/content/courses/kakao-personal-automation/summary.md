이 과정의 출발점이 된 영상이에요. 영상의 사례를 그대로 따라 하기보다, 영상이 보여 준 방식이 다섯 갈래 중 어디에 있는지, 무엇이 위험한지를 먼저 정리해요.

## 이 과정에서 다루는 것

카카오톡 비즈니스 채널(공식 API) 승인 없이, **개인 계정**으로 카톡 일을 자동화하는 방식은 크게 다섯 갈래예요. 이 과정은 다섯 가지를 **같은 틀**(대상 · 원리 · 할 수 있는 것 · 위험 · 언제 쓰나)로 나란히 놓고, 내 상황에 맞는 하나를 고르게 돕습니다. 실제 구현 실습은 이미 있는 두 과정으로 이어 줘요.

1. Claude + PlayMCP 「나와의 채팅방」
2. OS 접근성(Accessibility) API + AI
3. Computer Use · 매크로
4. 안드로이드 알림 기반(메신저봇R · MacroDroid)
5. 비공식 로컬 DB 해독 · LOCO 프로토콜 (권하지 않음)

원칙은 셋이에요.

- **공식 기능이 아닌 방식은 모두 약관·계정 제한 위험이 있다**고 보고 시작해요. "위험 없음"이라고 말할 근거는 없어요.
- **바깥으로 나가는 일**(자동 답장, 세금계산서 발행, ERP 입력, 코드 수정 반영)은 **사람이 승인한 뒤에만** 실행해요.
- 내 실제 방 이름·대화 내용은 강의 자료·로그·보고에 남기지 않아요.

## 전체 흐름

**1부 · 큰 그림**
1. **1강 다섯 갈래 한눈에 보기**: 비교표와 공통 원칙. (25분)

**2부 · 방식별 살펴보기**
2. **2강 Claude + PlayMCP 나와의 채팅방**: 공식 제공 기능으로 나에게만 보내기. (30분)
3. **3강 OS 접근성 API + AI**: PC 카톡 화면을 접근성 트리로 읽기. (30분)
4. **4강 Computer Use · 매크로**: 화면을 보고 누르는 방식과 대량 발송의 함정. (25분)
5. **5강 안드로이드 알림 기반 봇**: 부계정·공기계로 알림을 받아 처리하기. (30분)
6. **6강 로컬 DB · LOCO**: 왜 권하지 않는지. (15분)

**3부 · 고르기와 실습**
7. **7강 고르는 법과 실습 안내**: 질문 다섯 개로 고르고, 실습 과정으로 넘어가기. (25분)

## 이어지는 실습 과정

- 2번 접근성 방식으로 카톡을 모아 일정·할 일까지 정리하려면 → [AI 통합 비서 만들기](/lectures/unified-inbox)
- 4번 안드로이드 부계정·공기계 방식으로 내 방 챗봇을 만들려면 → [카톡 오픈채팅 챗봇 만들기](/lectures/kakao-chatbot)

## 끝나면 할 수 있는 것

- 다섯 방식의 대상·원리·위험을 한 표로 설명해요.
- 근거 없는 "안전하다"는 주장을 가려내고, 위험을 낮추는 운영 규칙을 정해요.
- 내 목적에 맞는 방식 하나를 고르고, 맞는 실습 과정으로 넘어가요.
