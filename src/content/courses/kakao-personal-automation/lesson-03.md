> **주의.** 화면을 읽고 조작하는 것도 **자동화**예요. 공식 API 가 아니므로 "계정 정지 위험 없이 안전하다"고 말할 수 없어요. 빈도를 낮게, 범위를 좁게 쓰고, 방을 여는 순간 **읽음 처리**가 일어난다는 점을 먼저 받아들이고 시작해요.

## 대상

PC(맥·윈도) 카카오톡 앱에 보이는 대화방 목록과 말풍선이에요. 1:1 방, 단톡방이 주 대상이에요.

## 원리

운영체제가 화면 읽기 프로그램을 위해 제공하는 **접근성 트리**를 읽어요. 맥은 손쉬운 사용(Accessibility, AX), 윈도는 UI Automation 이에요. 화면 캡처를 글자로 바꾸는 방식이 아니라, 앱이 접근성용으로 내놓은 텍스트 구조를 읽는 방식이에요.

## 할 수 있는 것

- 대화 내용을 내 컴퓨터의 DB 로 모으기
- AI 로 메시지 유형 분류, 일정·할 일 후보 뽑기, 날짜·수량 어긋남 **경고**
- 답장 **초안** 만들기

## 원천 자료의 주장 중 그대로 옮기지 않은 것

- "수백 줄을 수 초 만에" — 방 수·창 상태·기기에 따라 달라서, 이 강의는 숫자를 약속하지 않아요. 직접 재 보세요.
- "자동 답장 전송, 세금계산서 자동 발행, ERP 자동 입력, 버그 코드 자동 수정" — 이런 일은 상대에게 닿거나 되돌리기 어려워요. 이 과정의 원칙은 **AI 는 초안·후보까지, 실행은 사람이 승인한 뒤**예요.

## 위험

| 위험 | 내용 | 줄이는 법 |
|---|---|---|
| 계정 제한 | 공식 API 아님. 제재 기준이 공개돼 있지 않음 | 하루 몇 번만, 정해진 방만 |
| 읽음 처리 | 방을 열면 상대에게 읽음으로 보임 | 안 읽은 방은 열지 않기, 허용 범위 미리 정하기 |
| 창이 앞으로 | 수집 중 카톡 창이 앞으로 나와 작업 방해 | 쓰지 않는 시각에 실행 |
| 오작동 송신 | 입력창 조작이 엉뚱한 방에 들어갈 수 있음 | 보내기 동작은 자동화하지 않기 |
| 개인정보 | 대화 원문이 외부 AI 로 감 | 보내는 범위를 정하고, 로그엔 건수만 |

## 언제 쓰나

- 맞는 경우: 업무 단톡방이 많아 일정·할 일을 자주 놓칠 때, 컴퓨터 앞에서 일하는 시간이 길 때
- 안 맞는 경우: 24시간 즉시 응답이 필요할 때, 남의 방을 대신 운영할 때

## 실습은 여기서

이 방식으로 카톡을 모으고, 사람 대조로 검증하고, 일정·할 일을 승인 뒤에만 캘린더에 올리는 전 과정은 [AI 통합 비서 만들기](/lectures/unified-inbox) 과정에서 3부 8강으로 실습해요.
